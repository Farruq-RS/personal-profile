# Semantic HTML Personal Profile Page

## Project Overview
This project is a simple personal profile web page built using **semantic HTML5**.  
The goal of this task is to understand proper HTML structure, accessibility, and best practices used in real-world web development.

---

## Tools Used
- Visual Studio Code (VS Code)
- Web Browser (Google Chrome/Firefox)
- HTML5

---

## Files Included
- `index.html` – Main HTML file containing the semantic structure of the profile page
- `README.md` – Project documentation

---

## Features Implemented
- Semantic HTML elements such as:
  - `<header>`
  - `<nav>`
  - `<section>`
  - `<article>`
  - `<footer>`
- Proper heading structure (`<h1>` to `<h2>`)
- Profile image with `alt` attribute for accessibility
- Internal navigation using anchor links
- Clean and readable HTML code with comments explaining semantic usage

---

## Accessibility & Best Practices
- Used semantic elements instead of generic `<div>` tags
- Added `alt` text to images for screen readers
- Followed proper HTML document structure
- Ensured compatibility by testing in multiple browsers

---

## How to Run the Project
1. Download or clone the repository
2. Open the `index.html` file in any web browser
3. Navigate through sections using the menu links
